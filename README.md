# Enterpret Offsite 2026 Photobook

A small retro-style web photobook for Enterpret's 2026 offsite.

## What it does

- Plays an ASCII video background.
- Shows a desktop-style "Memories" folder.
- Opens a scrapbook viewer to browse photos in `photos/`.

## How to use

1. Add photos to the `photos/` folder.
2. (Recommended for `file://` usage) update `photos-manifest.js` with filenames.
3. Open `index.html` in a browser.

## Notes

- Best experience on desktop screens.
- Supports common image formats: jpg, jpeg, png, gif, webp, avif.
